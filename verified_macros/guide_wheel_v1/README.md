# Направляющее колесо — версия 1

Статус: пользователь подтвердил успешный запуск 21.11.2026.
Среда: T-FLEX CAD 17; установленная сборка API 17.0.85.0.
Запуск: внутри нового пустого 3D-документа.
Точка входа: ParametricGuideWheel.Macro.Run().

Строит:
- обод с двумя ребордами;
- прямоугольную наружную канавку;
- ступицу;
- две кольцевые торцевые выборки;
- сквозное осевое отверстие.

Особенности рабочей версии:
- размеры операций заданы числовыми Parameter;
- зависимые размеры рассчитываются в C#;
- отдельная API-сессия не создаётся;
- Application.IsSessionInitialized не используется;
- дополнительный Regenerate после EndChanges исключён.

Ограничение:
изменение переменных после построения не обеспечивает
автоматическое изменение размеров операций.

История:
версия с формулами и Parameter(Variable) не построилась.
Точная причина не установлена: в исправленном варианте
одновременно изменены несколько элементов.
