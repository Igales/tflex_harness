# Рабочий набор MCP для 3D-моделей T-FLEX

Целевой клиент: режим «Поиск» с коннектором T-FLEX Docs. Сервер: `serve_mcp_full.py`.
Экспериментальная поставка требует сквозной приёмки на Windows. Не считать набор
универсальным редактором произвольной геометрии только по успешным Python-тестам.

## Что входит в кандидат

| Задача | Инструмент и граница |
| --- | --- |
| Обнаружить CAD и открыть контекст | `get_bridge_status`, `get_document_snapshot`: документы, переменные, операции, выделение, ограниченный снимок состояния |
| Исследовать объект | `get_model_object`: схема свойства и числовое свойство API с единицей, если её возвращает CAD. Это не самостоятельная геометрическая проверка |
| Открыть GRB, показать 3D, активировать и закрыть неизменённую модель | `submit_model_operation`: `open_grb`, `activate`, `show_3d`, `close`. Для открытия принимается имя GRB внутри рабочей папки |
| Изменить параметры и перестроить | `set_variable`, `bind_parameter`, `regenerate`. Число передаётся в единице переменной. Формул, произвольных сценариев и пакетной транзакции пока нет |
| Сохранить и экспортировать | `save_copy`, `export_step` под новым именем в `artifacts/tflex_docs/mcp_models`. Сохранение поверх оригинала и пути вне папки не доступны |
| Создать GRB | `create_model_from_recipe`: один уже существующий рецепт контрольного выдавливания с фиксированными размерами. Сервер использует проверяемый исходник рецепта, а не код из промпта. Возможна компиляция рецепта; произвольный C# не нужен |
| Получить результат | `get_model_operation_result`, `get_model_creation_result`: чтение по тому же `job_id`; после тайм-аута не отправлять задачу повторно под другим ID |

## Безопасный запуск и приёмка

На тестовых копиях запустить `Start-TFlexFull.ps1 -EnableBridgeRead -EnableBridgeEdit`.
Флаг `-EnableRun` для этого набора не нужен. Для документов GUI сначала выбрать
точную пару `session_id` и `doc_id`; исключение `open_grb`, где выбирается имя файла.
`get_model_capabilities` показывает папку и список действий. Все GUI-операции
изменения проходят через существующий `prepare`/`commit` с Review. Сеанс создания
отдельный от GUI; успешный отчёт о сохранении не доказывает размеры или повторное
открытие. Запуск отдельного процесса не является песочницей.

Приёмка одной поставкой: чтение при двух открытых моделях; создание контрольного
GRB; его отдельное открытие; изменение переменной в копии; сохранение новой копии
и STEP; закрытие/открытие результата и сверка. Отдельно проверить устаревший
`doc_id`, попытку перезаписи, выход пути за папку, повтор `job_id`, тайм-аут и
неуспех перестроения. Замерить задержку и карточки «Поиска» отдельно от окна CAD.

## Что требуется для полноценного моделирования

1. **Версионированная спецификация модели.** Параметры, единицы, координаты,
   ссылки на тела/операции, допуски и заранее заданное имя результата. На входе
   текст или чертёж ЕСКД; критически неоднозначный размер блокирует запуск.
2. **Типизированные операции геометрии.** Эскиз и профиль, выдавливание и
   вращение, отверстия и вырезы, булевы операции, фаски, скругления. Добавить
   изменение существующей операции по устойчивой ссылке. Не считать
   поддержанными произвольные поверхности, сборки и резьбы пока для них
   не определены контракт и отдельные регрессии.
3. **Один план на задачу.** Новая деталь или правка открытой копии: проверка
   версии цели, резервная копия, проверка операций, перестроение, контроль
   размеров и тел, сохранение и при необходимости экспорт. Проверять
   реакцию на ошибку посередине и повторный вызов. Один Review CAD
   на пакет; отсутствие карточек «Поиска» проверять отдельно.
4. **Проверка результата.** Различать выполненные операции, успешное
   перестроение, верификацию размеров/связей, сохранение, экспорт и повторное
   открытие. Провести приёмку на чертеже фланца и на изменении уже открытой
   модели с двумя телами; изменения не должны затрагивать постороннее тело.

Граница выпуска: «Рабочий набор операций» и «Создание/изменение геометрии
по чертежу» имеют разные критерии приёмки. Перечень выше не означает, что
четыре пункта полностью реализованы в кандидате.
